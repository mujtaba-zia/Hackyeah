# Repo Isles

Your repositories, pull requests and pipelines as a living world of floating islands.

Work in progress: the product is being built in small, reviewed pull requests.
[`docs/SPEC.md`](docs/SPEC.md) is the specification every piece is built against;
`shared/types.ts` is the binding data contract between the layers.

The previous prototype in this repository, *Living City*, is preserved on the
[`living-city`](../../tree/living-city) branch and the `living-city-final` tag.

```bash
npm install
npm run check   # typecheck + tests
```

Requires Node 22.12 or newer.
